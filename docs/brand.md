# FixZone Brand Memory

## Logo

Official logo asset:

- `assets/brand/fixzone-logo.png`

The logo uses a black premium-tech background, white metallic lettering, blue accent lighting, a smartphone outline, and a wrench/tool mark integrated into the device icon.

## Official Color Palette

| Name | Hex | Usage |
| --- | --- | --- |
| Primary Blue | `#2F6FFF` | Accents, buttons, details, icons |
| Secondary Blue | `#4A8DFF` | Gradients, hover states, illumination |
| Deep Blue | `#1F4FCC` | Shadows, depth, dark backgrounds |
| Base Black | `#0A0A0A` | Main premium brand background |
| Dark Gray | `#1C1C1C` | Cards, sections, surfaces |
| White | `#FFFFFF` | Main text |
| Light Gray | `#BFBFBF` | Secondary text |

## Typography

Primary typography for logo and headings:

- Montserrat Bold
- Montserrat SemiBold
- Alternative: Poppins Bold

Secondary typography for body text:

- Montserrat Regular
- Alternative: Inter

Heading style:

- Use uppercase for titles, matching the logo style.
- Keep copy short, direct, and trustworthy.

Example copy:

- WE FIX FAST. YOU RELAX.
- REPARACION PROFESIONAL
- MICROSOLDADURA EXPERTA

## Visual Elements

Icon style:

- Thin line icons.
- Minimalist construction.
- Primary icon color: `#2F6FFF`.

Core motifs:

- Wrench: tool, repair, solution.
- Smartphone outline: phone repair specialty.
- Dynamic lines: speed and motion.
- Microchip: advanced technical skill and microsoldering expertise.

## General Visual Style

- Deep black background, inspired by premium tech brands.
- Soft blue glow and lighting effects.
- High contrast.
- Clean, premium, technology-focused aesthetic.
- Avoid noisy decoration; the brand should feel precise, fast, and expert.
